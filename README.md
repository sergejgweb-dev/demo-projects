# IRON HOUSE FITNESS — Website demo

This responsive static website is built with HTML, CSS and vanilla JavaScript. No packages or server are needed.

## How to open the page

Open `index.html` in a web browser. To edit the project, open the whole folder in a code editor and refresh the page after making changes.

## What each file does

- `index.html` contains the page sections: hero, about, programs, trainers, membership, schedule, gallery and contact.
- `style.css` controls colors, typography, layout and responsive behavior. The phone layout rules are near the bottom.
- `script.js` controls the mobile menu and the demo contact form confirmation.

## Demo notes

The trial form checks required fields and displays a confirmation, but does not send data anywhere. Contact details, names, times and prices are examples and should be replaced with real information before launch. Photos and Google Fonts load from the internet.

## A good next step for learning

Change a heading in `index.html`, find the `--orange` color near the top of `style.css`, and refresh the page. You will see how HTML changes the text and CSS changes the appearance.
